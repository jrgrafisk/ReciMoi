Del fra Instagram på iPhone

Lav denne genvej én gang (ca. 2 minutter) i appen Genveje. Så står “Opskrifter” i Instagrams delemenu.

  1. Åbn Genveje → tryk + (ny genvej). Navngiv den Opskrifter.
  2. Tryk på ⓘ (indstillinger) → slå Vis i delingsark til. Under “Modtag” vælg kun URL’er (og evt. Tekst). Tryk Udført.
  3. Tilføj handlingen URL-kod (søg “URL”). Sæt dens input til Input fra genvej.
  4. Tilføj handlingen Tekst og skriv præcis dette, og tilføj så variablen URL-kodet tekst lige efter:
  5. Tilføj handlingen Åbn URL’er, og sæt dens input til Tekst fra forrige trin.
  6. I Instagram: Del → rul til højre i rækken af apps → Mere → find Opskrifter og tryk på stjernen/+ for at flytte den øverst.

Når du deler, åbnes Safari med opslaget gemt, og du vælger kategori. Tip: tilføj også siden til hjemmeskærmen (Del → Føj til hjemmeskærm).

Adressen ovenfor er “localhost”. Åbn denne side fra iPhonen via computerens netværksadresse (vist når serveren starter), ellers peger genvejen forkert.
